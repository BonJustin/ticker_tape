Rsync from my internal SSD static web root folder (output by python `build_site.py`) to my VPS domain [jmbsquared.com](https://www.jmbsquared.com/).

```bash
rsync -avz --delete /run/media/bonju/SSD/jmbsquared.com  justinmichaelbonanno@jmbsquared.com:
```

***

Rsync from internal SSD to [justinmichaelbonanno.com](https://www.justinmichaelbonanno.com/)

```bash
rsync -avz --delete /run/media/bonju/SSD/justinmichaelbonanno.com  justinmichaelbonanno@justinmichaelbonanno.com:
```
