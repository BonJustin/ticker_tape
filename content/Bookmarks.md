#### Computers & Programming

[7-zip](https://www.7-zip.org/) \
*Open source encryption, quite versatile…*

[Bitwarden Password Strength Calculator](https://bitwarden.com/password-strength/) \
*Bitwarden*

[CommonMark specification](https://spec.commonmark.org/0.31.2/) \

[Compart](https://www.compart.com/en/unicode/html) \

[KeePass](https://keepass.info/) \
**Deprecated, use KeePassXC.** \

[Kiwix](https://get.kiwix.org/en/) \
*ZIM reader, website to ZIM converter, library of precompiled ZIM files for saving websites for offline use… All of Wikipedia, all of Project Gutenberg.*

[Mongoose](https://mongoose.ws/binary/) \

[Pico.css](https://picocss.com/) \
