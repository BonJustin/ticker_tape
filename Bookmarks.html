    KeePass
    Deprecated, use KeePassXC.
    KeePass Password Safe is a secure password database for Windows, with ports to all other platforms. It’s open source, and the database file can be safely served from a webserver, which automatically syncs with devices for offline use

    Kiwix
    ZIM reader, website to ZIM converter, library of precompiled ZIM files for saving websites for offline use… All of Wikipedia, all of Project Gutenberg.

    C++ software for local inference with open-weight models in GGUF format.

    Open source SVG icon library…

    Mongoose is a portable executable availabe for Windows/Linux/macOS. When opened it will serve the folder it is contained in to localhost.

    Picocrypt is a portable, cross-platform gui/cli encrytion and decryption tool…
