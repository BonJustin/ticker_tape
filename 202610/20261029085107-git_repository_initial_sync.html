Initial Sync With New Git Repository

This assumes configuration of the local development environment and global git.

  1. Create a new, empty repository on Github. **Do not initialize with README, .gitignore, or license.
  2. From the terminal, navigate to your project root and run: git init
  3. If not already present, create a .gitignore file in the project root with appropriate exclusions.
  4. Stage all files with: git add .
  5. Make initial commit with: git commit -m "initialization message"
  6. Rename default branch to main for consistency: git branch -M main
  7. Link the local repository the remote repository. Depending on the global git configuration:
    • SSH: git remote add origin git@github.com:USERNAME/REPOSITORY.git
    • HTTPS: git remote add origin https://github.com/USERNAME/REPOSITORY.git
  8. Push the codebase to the remote repository: git push -u origin main
