Exhaustive Field Reference

1. Core Structure & Metadata

Field Status Syntax / Value Details
BEGIN Mandatory BEGIN:VCARD Must be the very first line of every card.
VERSION Mandatory VERSION:4.0 Must immediately follow BEGIN:VCARD.
UID Required UID:urn:<scheme>:<id> Persistent unique identifier across systems. Format must be a valid URI (e.g., urn:contact:12345678901234).
REV Optional REV:YYYYMMDD'T'HHMMSS'Z' Revision timestamp in UTC. Used by sync engines to determine the most recent edit.
END Mandatory END:VCARD Must be the final line of every card.

2. Name & Display Properties

Field Status Syntax / Components Details
FN Mandatory Single text string Formatted Name. The primary human-readable display string in address books. Commas must be escaped (\,).
N Recommended Family;Given;Additional;Prefix;Suffix Structured Name. Used for sorting by last name. Semicolons separate the 5 positional components. Empty parts are left blank (e.g., Doe;Jane;;;).
NICKNAME Optional Comma-separated strings Informal names or aliases (e.g., NICKNAME:Bob,Bobby).

3. Organizational & Role Fields

Field Status Syntax / Components Details
ORG Optional Company;Department;Unit Organization structure. Semicolons denote hierarchy (e.g., Acme;Engineering;Firmware).
TITLE Optional Single text string Job title within the organization (e.g., TITLE:Senior Engineer).
ROLE Optional Single text string Business role or function (e.g., ROLE:Project Lead or ROLE:Consultant).

4. Telephones (TEL)

vCard 4.0 standardizes phone numbers using VALUE=uri:tel:... in international E.164 format (+CountryCode-Area-Number).

  • Common Types (TYPE=):
    • cell (or mobile): Mobile device (voice + text assumed).
    • work: Workplace telephone.
    • home: Home landline.
    • voice: Explicitly voice-capable.
    • text: Explicitly SMS/message-capable.
    • main: Switchboard / general line for an organization.
    • fax: Fax machine.
    • pref: The primary number to display or dial.
  • Extensions: Added with ;ext= at the end of the URI:
    • TEL;TYPE="work,voice";VALUE=uri:tel:+1-555-019-9000;ext=104

5. Email Addresses (EMAIL)

Stores the email address with an optional context type.

  • Valid Types (TYPE=):
    • home: Personal email address.
    • work: Corporate / professional email address.
    • other: Secondary / miscellaneous address.
    • pref: Mark which address your email client should pick by default.
  • Combining Types: Combine with quotes: EMAIL;TYPE="work,pref":jane@company.com.

6. Physical Addresses (ADR)

Addresses use a 7-part positional semicolon-delimited format:

ADR;TYPE=<type>:PO_Box;Extended_Address;Street_Address;Locality(City);Region(State);Postal_Code;Country
  • Empty Components: The first two parts (PO Box and Extended Address) are rarely used today, which is why standard street addresses start with two semicolons: ADR:;;123 Main St;Springfield;IL;62701;USA.
  • Multiline Streets: Separate apartment or suite numbers using literal \n: ADR;TYPE=work:;;Suite 400\n100 Tech Way;Austin;TX;78701;USA
  • Valid Types: home, work, pref.

7. Web & Instant Messaging

Field Syntax / Values Details
URL URL;TYPE=<type>:https://... Websites, blogs, or public profiles. Types: work, home, other.
IMPP IMPP;TYPE=<type>:<protocol>:<handle> Instant Messaging. Examples: xmpp:user@domain.com, sip:user@domain.com.

8. Personal & Dates

Field Syntax / Values Details
BDAY YYYYMMDD or YYYY-MM-DD Birthday. If the birth year is unknown, the RFC allows the yearless format: --0412 (April 12).
ANNIVERSARY YYYYMMDD Wedding or milestone anniversary date.
GENDER M, F, O, N, U Gender identity per RFC 6350: Male, Female, Other, None, Unknown.

9. Categorization & Metadata

Field Syntax / Values Details
CATEGORIES Comma-separated list Tags and contact groups (e.g., CATEGORIES:Friends,Family,Tennis Club). Maps to Google Labels, Apple Groups, and Proton Tags.
NOTE Escaped text string Free-form notes. Multi-line notes must use literal \n instead of actual Return key strokes.
TZ IANA Timezone string Geographic timezone (e.g., TZ:America/New_York or TZ:Europe/Stockholm).
GEO geo:latitude,longitude Coordinates of the contact’s home or office (e.g., GEO:geo:37.7749,-122.4194).
LANG BCP 47 language tag Primary spoken/written language (e.g., LANG:en-US, LANG:sv-SE).
