A Fun Little Shell Script

I wanted to make markdown note creation fit my digital archive format, and speed up the process of setting up each document…

This was a fun 5 minute quick-fix. I used Gemini 3.8 Flash for this, and it was correct the first attempt. I’m curious if my local models would accomplish it as easily?

After a couple preliminary investigatory prompts, I used the following prompt:

...the shell script route works, but not quite
suitable to my needs. essentially, i would like to be able to navigate to a
directory, run my script and have it do the following:

1.  request an string input.
2.  the string input should be validated.
    * lowercase, internal spaces converted to hyphens, no leading or trailing spaces, only `-` and `_` special characters allowed.
2.  create a new markdown note in the cwd named `YYYYMMDDHHMMSS` (based on the
    current local system time) + `-` + `the string input` + `.md.`
3.  open the file in zed.
4.  inject YAML frontmatter, using the same time as the filename
    ```
    ---
    title: "TITLE"
    date_edtf: "YYYY-MM-DDTHH:MM:SS"
    keywords: ["KEYWORD"]
    ---

    ```

This produced the following shell script:

#!/usr/bin/env bash

set -euo pipefail

# 1. Prompt for user input
read -r -p "Note title: " TITLE_INPUT

# Exit cleanly if input was empty or canceled
if [ -z "${TITLE_INPUT// /}" ]; then
    echo "Aborted: Title cannot be empty." >&2
    exit 1
fi

# 2. Capture the exact current local time once for consistency
NOW=$(date +"%Y%m%d%H%M%S")
EDTF_DATE=$(date +"%Y-%m-%dT%H:%M:%S")

# 3. Clean the input string to make it safe for filenames (spaces -> hyphens, lowercased)
SLUG=$(echo "$TITLE_INPUT" | tr '[:upper:]' '[:lower:]' | tr -cs 'a-z0-9_' '-' | sed 's/^[-_]*//;s/[-_]*$//')

# Construct filename: YYYYMMDDHHMMSS-<input>.md in the current working directory
FILENAME="${NOW}-${SLUG}.md"

# 4. Populate frontmatter into the file
cat <<EOF > "$FILENAME"
---
title: "TITLE"
date_edtf: "$EDTF_DATE"
keywords: ["KEYWORD"]
---

EOF

# 5. Resolve Zed command (native or Flatpak on Aurora)
if command -v zed >/dev/null 2>&1; then
    ZED_CMD="zed"
elif flatpak info dev.zed.Zed >/dev/null 2>&1; then
    ZED_CMD="flatpak run dev.zed.Zed"
else
    echo "Error: Zed could not be found." >&2
    exit 1
fi

# 6. Open the file in Zed
# Using :5:1 drops the cursor right below the frontmatter on line 5, ready to write
$ZED_CMD "${FILENAME}:5:1"

I saved the script to ~/.local/bin/ and made it executable (chmod +x mdnote.sh).

This file is the first test.
