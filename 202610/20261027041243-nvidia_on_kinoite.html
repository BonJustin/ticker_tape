Installing NVIDIA 2080 Ti On Fedora Kinoite

Note: This has not been tested yet!

Body

Follow this phased sequence to establish the host driver, enable containerized hardware access for local inference engines, and configure gaming runtimes.

Phase 1: Host System Preparation and Driver Layering

  1. Synchronize OS Tree and Reboot (if updates exist):

    sudo rpm-ostree upgrade

    If a new deployment is staged, execute systemctl reboot before proceeding.

  2. Add RPM Fusion Repositories:

    sudo rpm-ostree install \
  https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm \
  https://mirrors.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm

    Reboot to finalize repository layering:

    systemctl reboot

  3. Install Driver Packages and Dependencies in a Single Transaction: Layer the core driver, CUDA runtime, 32-bit userland libraries (required for legacy/Vulkan game translation layers), and the container toolkit:

    sudo rpm-ostree install \
  akmod-nvidia \
  xorg-x11-drv-nvidia \
  xorg-x11-drv-nvidia-cuda \
  xorg-x11-drv-nvidia-libs.i686 \
  xorg-x11-drv-nvidia-cuda-libs.i686

  4. Append Kernel Parameters to Suppress Nouveau:

    sudo rpm-ostree kargs \
  --append=rd.driver.blacklist=nouveau \
  --append=modprobe.blacklist=nouveau \
  --append=nvidia-drm.modeset=1

  5. Reboot the System:

    systemctl reboot

  6. Validate Host Driver Operation: After boot, verify the driver and CUDA version:

    nvidia-smi

    Ensure the RTX 2080 Ti appears, indicating the kernel module compiled and bound correctly.

Phase 2: Configuration for Local Open-Weight Models

To maintain atomic immutability, run inference servers (e.g., Ollama, vLLM, or llama-server) via rootless Podman containers.

  1. Add NVIDIA Container Toolkit Repository:

    curl -s -L https://nvidia.github.io/libnvidia-container/stable/rpm/nvidia-container-toolkit.repo | \
  sudo tee /etc/yum.repos.d/nvidia-container-toolkit.repo

  2. Install the Toolkit on Host Layer:

    sudo rpm-ostree install nvidia-container-toolkit
systemctl reboot

  3. Generate Container Device Interface (CDI) Specification: This allows Podman to pass the GPU into OCI containers without privileged daemon intervention:

    sudo nvidia-ctk cdi generate --output=/etc/cdi/nvidia.yaml

  4. Verify Containerized Inference Capabilities: Run a diagnostic container targeting the Turing compute capability (sm_75):

    podman run --rm --device nvidia.com/gpu=all docker.io/nvidia/cuda:12.4.1-base-ubi9 nvidia-smi

  5. Deploy Local Model Server (Example: Ollama):

    podman run -d \
  --name ollama \
  --device nvidia.com/gpu=all \
  -p 11434:11434 \
  -v ollama_models:/root/.ollama \
  --restart always \
  docker.io/ollama/ollama:latest

Phase 3: Configuration for Light Gaming

Kinoite standardizes graphical application delivery via Flatpak.

  1. Install Steam via Flatpak:

    flatpak install --user flathub com.valvesoftware.Steam

  2. Synchronize Matching NVIDIA Flatpak Runtime: Flatpak must run userland drivers matching the host kernel module:

    flatpak update

    Flatpak detects the active host NVIDIA driver version and automatically pulls the corresponding org.freedesktop.Platform.GL.nvidia-* runtime.

  3. Launch Steam and Verify GPU Acceleration:

    flatpak run com.valvesoftware.Steam

    Check Steam -> Settings -> Display to confirm the RTX 2080 Ti is designated as the primary renderer.
