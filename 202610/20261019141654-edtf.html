EDTF/ISO 8601-2

EDTF Library of Congress Extended Date/Time Format is a timestamp format specifically for archival work.
    by Justin Bonanno

    EDTF = Library of Congress Extended Date/Time Format = ISO 8601-2.

    Level 1: Resolution

    Description EDTF String Note
    “Sometime in 1999” 1999 Only the year is known.
    “Sometime in October of 1999” 1999-10 Year and month known.
    “Sometime on October 19, 1999” 1999-10-19 Full date known.

    Level 2: Fuzziness

    Tilde (~) for Approximation

    Description EDTF String Note
    “Approximately 1999” 1999~
    “Approximately October 1999 1999-10~
    “Approximately 19 October 1999 1999-10-19~

    Question Mark (?) for Uncertainty

    Description EDTF String Note
    “Possibly 1999” 1999?
    “Possibly 19 October 1999” 1999-10-19?

    Level 3: Ranges & Boundaries

    Closed Ranges (Start and End)

    Description EDTF String Note
    “Between 1990 and 1995” 1990/1995
    “From January 1999 to March 1999” 1999-01/1999-03

    Open Ranges (One-sided)

    Description EDTF String Note
    “Since 1990” 1990/
    “Until 1990” /1995

    Level 4: High Precision

    Precision & Time

    Description EDTF String Note
    “19 October 1999 at 2:30 PM” 1999-10-19T14:30:00
    “Around 2:30 PM on October 19, 1999” 1999-10-19T14:30:00~

    Level 5: Complexity

    Description EDTF String Note
    “Roughly between 1920 and 1925” 1920~/1925~ Range with approximation on both ends.
    “Possibly 1940, but definitely in May” 1940?-05 Uncertain year with known month.
    “From around 1950 onwards” 1950~/
    “Between October 1999 and November 1999 (approximate) 1999-10/1999-11~

    Note: the tilde (~) character has functional use in markdown for strikethrough, subscripts, and fenced code blocks, so it may be necessary to use escape characters to control the rendering of tildes when converting between markdown and other formats.
